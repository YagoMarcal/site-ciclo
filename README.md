# ♻️ Ciclo

O **Ciclo** é um site multipáginas que aborda informações sobre **sustentabilidade** e **impacto social**, com foco em **acessibilidade para pessoas com deficiência**.

Projeto desenvolvido para a disciplina de **Desenvolvimento Web Front-End**.

##  Objetivo

Aplicar os conceitos de desenvolvimento front-end na criação de um site informativo, organizado em várias páginas, que seja inclusivo e de fácil navegação para todos os públicos.

##  Páginas do site

| Página | Descrição |
|---|---|
| `index.html` | Página inicial |
| `sobre.html` | Sobre o projeto |
| `projetos.html` | Projetos e iniciativas |
| `impacto.html` | Impacto social e ambiental |
| `acessibilidade.html` | Recursos e informações de acessibilidade |
| `noticias.html` | Notícias relacionadas ao tema |
| `galeria.html` | Galeria de imagens |
| `midia.html` | Conteúdos de mídia (vídeo/áudio) [confirme] |
| `orcamento_hospedagem.html` | Orçamento de hospedagem do site |
| `contato.html` | Formulário/informações de contato |
